# SnapName
Camera app that saves photos to Pictures/SnapName, named by subject,
e.g. dog-grass-pet_20261126_104400.jpg. Android 10+. Labelling runs on the phone.

## Build with Android Studio
Open this folder, let it sync, plug in your phone (USB debugging on), press Run.

## Build with GitHub (no install)
1. Create a repository and upload the contents of this folder, including .github
   (if the web uploader skips it, create .github/workflows/build.yml by hand).
2. Open the Actions tab and wait for "Build APK" (or run it manually).
3. Download the SnapName-apk artifact, unzip, and open the APK on your phone.
   Android will ask you to allow installing from that source.
